# Module 01 – Opleidingsquiz

## Wat doet het programma?
Het programma stelt vragen over programmeren en de opleiding. De gebruiker kiest telkens een antwoord uit vier opties. Na ieder antwoord wordt aangegeven of het goed of fout is en wordt de score bijgewerkt.

Het programma heeft de volgende functies:
- Vragen in willekeurige volgorde stellen.
- Meerkeuzevragen met vier antwoordmogelijkheden.
- Controleren of het antwoord goed of fout is.
- De score en het behaalde percentage tonen.
- Een beoordeling geven op basis van de score.
- De hoogste score opslaan in `highscore.txt`.
- De mogelijkheid bieden om de quiz opnieuw te spelen.

## Hoe start je het programma?
1. Download of clone de repository van GitHub.
2. Open de projectmap in Visual Studio Code of een terminal.
3. Controleer of Python 3 is geïnstalleerd.
4. Start het programma met het volgende commando: python main.py of python3 main.py
5. Beantwoord de vragen door een getal van 1 tot en met 4 in te voeren.
6. Aan het einde kun je kiezen of je de quiz opnieuw wilt spelen.
